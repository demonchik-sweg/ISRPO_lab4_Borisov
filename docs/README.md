# Документация проекта Geometric Lib

## 1. Общее описание решения
Данный проект представляет собой библиотеку для вычисления площади и периметра различных геометрических фигур. 
На данный момент библиотека поддерживает следующие фигуры:
* Круг (circle.py)
* Квадрат (square.py)
* Прямоугольник (rectangle.py)
* Треугольник (triangle.py)

Все функции принимают числовые значения и возвращают результат вычислений.

## 2. Описание функций с примерами вызова

### Прямоугольник (rectangle.py)
* `area(a, b)` - вычисляет площадь прямоугольника со сторонами `a` и `b`.
  * Пример вызова: `area(5, 10)` вернет `50`.
* `perimeter(a, b)` - вычисляет периметр прямоугольника со сторонами `a` и `b`.
  * Пример вызова: `perimeter(5, 10)` вернет `30`.

### Треугольник (triangle.py)
* `area(a, h)` - вычисляет площадь треугольника по основанию `a` и высоте `h`.
  * Пример вызова: `area(4, 6)` вернет `12.0`.
* `perimeter(a, b, c)` - вычисляет периметр треугольника со сторонами `a`, `b` и `c`.
  * Пример вызова: `perimeter(3, 4, 5)` вернет `12`.

### Круг (circle.py)
* `area(r)`- вычисляет площадь круга радиуса `r`.
  * Пример вызова: `area(3)` вернет `28.274...`.
* `perimeter(r)`- вычисляет длину окружности радиуса `r`.
  * Пример вызова: `perimeter(3)` вернет `18.849...`.

### Квадрат (square.py)
* `area(a)` - вычисляет площадь квадрата со стороной `a`.
  * Пример вызова: `area(4)` вернет `16`.
* `perimeter(a)`  вычисляет периметр квадрата со стороной `a`.
  * Пример вызова: `perimeter(4)` вернет `16`.
